| 鉴权 | 代理侧 nginx 校验 + `LID` cookie（图书馆登录标识）+ `ASP.NET_SessionId`（知网会话）；**直连 HTTP 会被代理拦回登录页**，所有请求必须在浏览器页面上下文内发（`fetch(..., {credentials:'same-origin'})`） |

## 二、检索与导出协议（已嗅探验证）

### 2.1 检索（两步）

```
① POST /kns55/request/SearchHandler.ashx
   Content-Type: application/x-www-form-urlencoded
   关键字段：
     NaviCode=*                  PageName=ASP.brief_result_aspx
     DbPrefix=SCDB               DbCatalog=中国学术文献网络出版总库
     ConfigFile=SCDB.xml         db_opt=中国学术文献网络出版总库
     db_value=中国学术期刊网络出版总库,中国博士学位论文全文数据库,
              中国优秀硕士学位论文全文数据库,中国重要会议论文全文数据库,
              中国重要报纸全文数据库,中国年鉴网络出版总库
     txt_1_sel=题名|主题|关键词|摘要|全文...   ← 检索字段
     txt_1_value1=<检索词1>      txt_1_value2=<检索词2，可选>
     txt_1_relation=#CNKI_AND|#CNKI_OR|#CNKI_NOT
     txt_1_special1==（精确）|%（模糊）
     publishdate_from=YYYY-MM-DD publishdate_to=YYYY-MM-DD  ← 时间过滤
     au_1_sel=作者,中英文作者,作者名称   au_1_sel2=机构,单位,作者单位,学位授予单位
     his=0                       __=<当前时间串>

② GET /kns55/brief/brief.aspx?pagename=ASP.brief_result_aspx&dbPrefix=SCDB
      &dbCatalog=<URL编码的库名>&ConfigFile=SCDB.xml&research=off&t=<时间戳>
   → 返回结果表 HTML；从中解析：
     - 命中总数：/共有记录(\d+)条/
     - 检索会话号：/name=QueryID value=(\d+)/
     - 记录 ID（checkbox）：/name=FileNameS[^>]*value=([^ >]+)/ 或反序
       格式：<DbCode>!<FileName>!<某序号>!<QueryID>，如 CJFQ2025!XDXK202519014!1!7
```

### 2.2 引文导出（GB/T 7714-2015）

```
① 把记录 ID 列表写入 cookie：
   document.cookie = 'FileNameS=' + encodeURIComponent('cnki:' + ids.join(',')) + ';path=/'
② GET /kns55/viewsave.aspx?TablePre=SCDB&QueryID=<qid>
   → 从中取 __VIEWSTATE 与 __VIEWSTATEGENERATOR（ASP.NET 回传校验）
③ POST /kns55/SaveSelectedNoteFormat.aspx
   __VIEWSTATE / __VIEWSTATEGENERATOR / TablePre=SCDB / QueryID=<qid>
   CookieName=FileNameS / clearall= / IsPrev= / displayMode=Refer   ← Refer=引文格式
   → 返回 GB/T 7714-2015 引文文本（纯文本行，可直接抄入开题/论文）
```

`displayMode` 可选值：`brief`（简单）/ `detail`（详细）/ `Refer`（引文）/
`self`（自定义字段）/ `RefWork` / `EndNote` / `NoteExpress` / `new` / `pdl`。

**注意**：KNS5.5 引文导出**不含页码**（老版平台字段缺失），如学校严格要求
"卷(期): 页码"格式，需另经知网新版（www.cnki.net）或期刊官网补页码。
