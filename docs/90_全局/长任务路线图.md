## 一、关键路径判断（先看这个）

学校时间轴是**前重后轻**：开题 09-15 → 论文初稿 **10-15** → 中期检查 10-30 →
定稿+查重 12-30 → 答辩 2027-03~04。这意味着：

1. **最紧急**：开题（09-15 截止）需要 ①系统定义冻结（前置）②文献综述
   （用户须上知网检索，AI 不可代替）③开题报告成文（内容稿已备）；
2. **最紧张**：论文初稿 10-15 前"开发主体"必须成形 → 需求分析和设计必须
   在 9 月内压缩完成，10 月起边开发边写论文（各包产物即论文章节素材，
   **写论文 = 改写已有文档，不二次创作**）；
3. 并行策略：定义冻结后，需求 → 设计 → 开发按包顺序快速过闸，
   论文章节随包产出同步改写。
