# 论文知识结构目录

本文件是论文资料导航和知识关系图，不代替冻结需求、系统设计或测试记录。论文事实以链接的权威项目文档及对应证据为准；第三方原始文献和学校资料仍保留在本地忽略的 `docs/90_全局/参考资料/`。

## 一、知识总图

```text
论文题目与研究对象
├─ 研究依据
│  ├─ 学校规范与交付要求
│  ├─ 已核对文献与真实阅读记录
│  └─ 研究范围、目标用户与非目标
├─ 系统工程事实
│  ├─ 需求：系统要解决什么问题、提供什么能力
│  ├─ 设计：系统如何分层、建模、存储和授权
│  ├─ 实现：代码与数据库迁移实际做了什么
│  ├─ 测试/验收：哪些行为按什么证据验证
│  └─ 部署：系统如何容器化并运行
└─ 论文表达
   ├─ 研究现状与问题边界
   ├─ 需求分析、系统设计、实现说明
   ├─ 测试与部署验证结果
   └─ 结论、限制与展望
```

## 三、推荐章节知识树

以下按学校七章结构整理，是写作导航；最终标题和分章方式仍服从用户/导师确认的论文提纲。

```text
1 绪论
├─ 研究背景与意义
├─ 国内外研究现状（来自文献证据，不等同项目需求）
├─ 研究目标、研究内容与研究方法
└─ 章节安排
2 相关技术介绍
├─ 后端框架与接口技术
├─ 前端框架与工程化
├─ 数据库与持久层
├─ 身份认证、授权与多小区数据隔离
└─ 缓存、并发控制与实时通信（只保留有实际解释价值的技术）
3 系统分析
├─ 研究对象、角色与系统边界
├─ 可行性分析
├─ 功能需求与核心业务流程
└─ 非功能需求
4 系统设计
├─ 总体架构与功能结构
├─ 权限模型及数据隔离
├─ 核心业务状态机与流程
└─ 数据库概念/逻辑设计
5 系统实现
├─ 小区与房屋、居民及居住关系
├─ 租住与房源服务
├─ 工单、排班与服务评价
├─ 公告、反馈会话与通知
├─ 公共资源预约
└─ 统计、权限及关键技术实现
6 系统测试与部署验证
├─ 测试范围、方法与环境
├─ 核心测试及结果
├─ 评估验收结论与证据限制
└─ 本地容器和云端演示部署验证（与业务测试区分）
7 总结与展望
├─ 已完成工作与证据支持的结论
├─ 项目限制
└─ 后续改进方向
参考文献
致谢
```

## 四、事实链与引用链

项目功能的论文表述按以下链条取证：

```text
系统定义 → 需求 → 设计 → 源码/数据库迁移 → 测试证据 → 验收/评估结论 → 部署证据
```

- 说“系统计划支持”：至少有现行需求依据。
- 说“系统设计采用”：需要设计文档依据。
- 说“系统实现了”：需要当前源码或数据库迁移依据。
- 说“系统验证通过/达到指标”：还需要对应测试或部署证据；需说明测试类型和范围。
- 说“研究证明/已有研究表明”：必须有可追溯文献原文、页段或可靠摘要依据；不以本项目实现替代文献证据。
- 说“创新、优于、显著提升、普遍存在、尚无研究”：需要比较对象和证据支持；否则收窄为本项目的设计选择、实现范围或检索观察。
