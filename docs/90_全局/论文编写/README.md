## 文献收录原则（2026-10-22 用户要求后确立）

**只收录实际读过全文的文献。** 仅题录、仅摘要、未取得可读文本的文献不进正文、
不进参考文献表。当前 36 篇 = 中文期刊 33 篇 + 学位论文 3 篇：

- **6 篇为图像型 PDF（无文本层）**，经逐页渲染成图后阅读——期刊 3 篇
  （陆向艳 2025、王科翔 2023、季玉洁 2025）、学位论文 3 篇（付昌昌 2019、
  包添文 2023、曹陈涵 2023）。**「无文本层」不等于「无内容」**：判断能否阅读
  必须以渲染后能否看清为准，不能只看 extract_text() 是否为空。
- **4 篇学位论文未纳入**——库中只有 .caj、无可读 PDF（金明俐、吴昌政、
  胡金宇、田海晴）。
- **4 篇外文未纳入**——1 篇 DOI 指向无关论文、1 篇业务域为服装租赁、
  1 篇无法定位、1 篇仅摘要。
- **1 篇已读但业务无关**未引用（轨道交通 ATS 缓存系统）。

逐篇核实结论见 [逐篇证据映射](文献综述/evidence-map.md) §二。
