# 逐篇证据映射（v4 正稿配套）

> **用途**：把[文献综述正稿](文献综述正稿.md)每一处引用回溯到可回查的原文位置、
> 所支撑的具体论点及与本项目的对应关系，供导师审核与答辩核查。
> **收录原则**：只登记**读过全文**的文献。仅题录、仅摘要、未取得可读文本的条目
> 一律不登记，也不进入正稿参考文献表。
> **阅读方式**：30 篇为原件文本层提取；6 篇原件为扫描图像、无文本层，经逐页
> 渲染成图后阅读（期刊 3 篇、学位论文 3 篇），图表与个别字词存疑处以原 PDF 为准。
> 建立时间：2026-10-22（v4）。
