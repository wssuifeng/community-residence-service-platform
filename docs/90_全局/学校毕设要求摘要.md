## 三、成绩构成与答辩（管理办法第八~十节）

- 总评成绩 = 指导教师 40% + 评阅教师 20% + 答辩小组 40%（百分制，
  90+/80+/70+/60+ 对应优/良/中/及格；优秀率 ≤15%、良好率 ≤35%）；
- 答辩：约 15 分钟/人（自述约 8 分钟 + 回答 ≥3 个问题），需 PPT，全程记录；
- 答辩资格门槛：开题报告及任务书、中期检查表、过程电子批阅稿（初稿/定稿/最终稿）、
  设计说明文完成、查重报告合格（答辩资格审查表附件 6）；
- 指导过程：学生求教与教师指导总次数 ≥6 次（指导过程记录表，附件 2，导师填写）。

## 六、论文提纲参考结构（学院样例口径，7 章）

```
1 绪论（研究背景及意义 / 国内外发展现状 / 研究目的和方法）
2 相关技术介绍（各框架 / 数据库 / 开发运行环境）
3 系统分析（任务概述 / 可行性分析 / 功能需求分析 / 性能需求分析）
4 系统详细设计（各模块设计 / 数据库设计：设计原则、E-R图、数据表）
5 系统实现（按模块逐节，配界面截图）
6 系统测试（测试目的 / 功能测试按模块）
7 总结与展望
```

对照本项目文档体系：3 章 ← 20_需求分析；4 章 ← 30_系统设计；5 章 ← 40_开发实施；
6 章 ← 50_系统测试；绪论/技术介绍 ← 90_全局/参考资料 + 技术选型调研。
**各包产物写论文时直接改写复用，不重复劳动。**
