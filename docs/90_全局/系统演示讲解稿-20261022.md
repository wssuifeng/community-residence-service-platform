- 本地前端：`http://localhost:18088`（推荐；当前本地 Docker Compose 环境运行中）

- 云端演示：`https://cloud-computing-webstatic.cc.cd`（需先开机 ECS）

## 推荐演示流程

1. **游客端**：展示首页、公告和公开房源；说明预约等业务需居民登录。
2. **居民端**：登录 `resident1`，展示首页、消息中心、个人中心，以及公告、工单、反馈和预约入口。
3. **社区管理员端**：登录 `admin1`，展示社区数据、居民/房屋、工单工作台、派单排班和服务人员业务管理。强调管理员权限仅限绑定社区。
4. **服务人员端**：登录 `staff1`，展示本人工作台、派单和工单处理信息。
5. **超级管理员端**：登录 `superadmin`，展示全局管理和系统账号权限入口。

## 演示注意事项

- 以浏览为主，避免新增、删除数据影响演示；不进行真实支付、查单、退款或支付渠道配置。
- 不执行 `docker compose down -v`，避免删除演示数据库卷。
- 若本地页面无法访问，先确认 Docker Desktop 运行，再检查项目的四个 Compose 容器。
- 云端图片与本机 `uploads/` 分离，本机图片不会自动上传云端。
