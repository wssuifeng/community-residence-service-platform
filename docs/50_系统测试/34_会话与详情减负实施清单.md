# 会话与详情减负实施清单

**目标**：将已采纳32和33落实到产品，详情负责业务，会话页负责完整沟通。
**结构**：保留conversation与feedback原模型；聚合只读列表，消息与发送仍经各来源原权限。三端共用工作区，路由页仅适配业务动作。
**技术**：既有Spring Boot/MyBatis/Vue3/TypeScript，不加组件库。

## 1. 数据契约（独立交付）
- ConversationInboxMapper：受身份/参与者/社区约束的聚合查询，来源键CONVERSATION:id或FEEDBACK:id；服务端搜索、未读、活动排序和分页。
- ConversationInboxService/Controller：列表、受权消息历史窗口（records/startAtUnread/firstUnreadMessageId/hasOlder/hasNewer）、反馈原子已读；首次有未读从首条他人未读开始，没有未读取最近窗口，后续游标请求不重复定位。V43仅新增反馈游标表，不改旧迁移；旧消息端点兼容。
- 测试先验证跨身份撞号、非参与者/越社区/服务人员反馈拒绝、匿名、游标归属和前移，再实现。
- 运行相关Maven测试，检查SQL解析/映射；完整接口任务本地提交。

## 2. 共享界面（独立交付）
- components/conversation/ConversationWorkspace：三段布局与业务适配容器。
- ConversationSourceNav/ConversationInboxList：分类、真实搜索/分页、未读和错误重试，props输入/events输出。
- composables/useConversationInbox：请求版本、列表去重与刷新；共享聊天引擎补窗口加载、草稿、可见消息已读，消息列表补底部跟随与阅读位置；未读筛选中当前读完的会话保留为已读，切换后移走。
- 三端入口保留原外层导航，旧conversation/:id定位同一源；反馈原匿名渲染、关闭只读、协议/看房动作继续复用。
- Vitest定向覆盖切换竞态、搜索分页、自己的消息、关闭/失败；vue-tsc与build；隔离浏览器检查三端尺寸与入口，不操作用户浏览器。

## 3. 详情收口（独立交付）
- 三端工单、两端反馈详情：保留业务内容/附件/动作，完整聊天换准确源入口；历史补群仍需显式管理动作。
- admin/lease/LeaseDetailView：顶部摘要，概览/合同与协议/费用记录/业务记录；复用原组件与表单，分区按需读取、独立重试。
- 仅验证沟通入口往返、协议和只读展示，不发起任何交易；相关测试与证据回写后本地提交。

执行按上述顺序；实际勾选和剩余项仅记50中控。中断时保留明确实现边界，不把设计稿或接口交付称全界面完成。


## cn局部密度实施补充（2026-10-17 用户截图修正）

沿用三段布局，不新增功能或重复视觉审批。外层三端Layout仅在conversations路径应用专用高度/留白，Shared Workspace负责紧凑页头、Pane负责聊天头及消息/输入空间分配，ChatMessageList负责姓名/时间外置与内容气泡，ChatComposer负责紧凑输入；原数据、事件、权限、已读和发送约束不变。

先记录同数据同视口下的消息区高度和单条文字高度，再调整并对比。验证标准：消息区获得主要高度、正常桌面无整页纵向溢出、姓名/时间位于气泡上方并紧邻，不设固定最小宽度，不拉开到整行两端（用户后续截图修正）、单行气泡不含两行元信息；小窗口仍可发送，图片完整可预览，补历史/未读定位及输入法发送规则保留。只回归会话相关组件，不回跑其它业务。

cn结果及尺寸对比见[evidence/cn-conversation-density-20261017](evidence/cn-conversation-density-20261017/README.md)，当前人工范围仍为25的三端会话。
