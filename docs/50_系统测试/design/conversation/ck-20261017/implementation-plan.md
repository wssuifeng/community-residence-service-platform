# 侧栏滚动条修正与详情页收口准备

目标：消除已采纳会话稿中左侧突兀的原生竖条，并给出与统一会话衔接的聚焦详情方案。不是本轮直接实施整套会话后端。

结构：正式后台滚动条在独立样式文件按既有.app-sidebar类局部生效，从main.ts加载；设计稿在其实际滚动nav上使用相同类，嵌入同一CSS作为展示副本。既有Vue组件及滚动机制不变。详情新布局只在33供审阅，不改现有业务。

步骤：
1. 独立浏览器复现原生轨道无局部样式，记录失败断言；明确实际滚动所有者，不用全局overflow:hidden掩盖。
2. 新增frontend/src/styles/sidebar-scrollbar.css、main.ts引入；修正cj精确稿实际滚动nav，用4px透明轨、悬停/焦点显现、无上下箭头；高对比保留可见滚动。
3. 用隔离浏览器验证设计稿以及正式样式在同名滚动容器上的行为，含到底、键盘、悬停/失焦、横向不溢出；只刷新相关设计截图，不重复114项旧设计检查或其它业务。
4. npm run build（含类型检查），更新32/33、设计验收例外、清单hash及阶段记录；本地提交不推送。

资源：主会话串行，无子Agent；所有浏览器测试独立headless/file://，不使用用户浏览器、不启动/停止正常服务、不读取业务数据、不交易。范围外：统一会话接口/消息历史迁移、租约业务规则、费用计算、详情大改，均不随本次CSS修复静默实施。
