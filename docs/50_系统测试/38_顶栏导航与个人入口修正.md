# 顶栏导航与个人入口修正

依据：用户2026-10-18在50阶段实际入口确认中的反馈；上游C10账号身份及C11消息通知、30 UI设计§2/§3既有三端布局、居民个人中心与通知路由。原通知/账号权限和后端契约保持。此文为本批聚焦修正说明，不修改冻结定义或扩大账号管理能力。

## 交互与范围

- 居民顶栏新增“消息中心”，指向既有`/resident/notifications`；“会话”保留为独立导航，通知页面选中消息中心。
- 三端共用姓名菜单按顺序显示“个人中心”“返回首页”“退出登录”；使用可键盘操作的按钮作为触发器，点击菜单后正常收起。
- 居民个人中心沿用`/resident/profile`；新增`/admin/profile`与`/staff/profile`复用公共账号信息页，仅展示当前登录会话已有的真实姓名、用户名和身份。管理端包含超级管理员，不调用他人资料接口。
- 返回首页分别为`/resident/home`、`/staff/dashboard`、`/admin/dashboard`，由当前身份决定，不进入游客首页。
- 公共AppHeader负责菜单呈现与路由跳转；公共账号页负责已有身份信息呈现。各端只增加路由装配，公共不引用端页面，不复制三套信息页。
- 顶栏导航可在有限宽度内横向滚动，姓名区不被挤出视口；不新增其它导航或账号字段编辑、密码操作。

## 验证与交付

原路由兼容夹具只增加两个明确的新个人中心路由，其他路径/角色/重定向保持。验证三端及超管菜单落点、居民消息中心高亮、键盘开启菜单及桌面/平板布局；本轮不操作用户浏览器、业务数据或金融接口。实现与结果见50中控cy及对应evidence。
