# cn 会话空间与消息样式修正

用户要求扩大消息记录区、缩小消息卡片，参考QQ将姓名和时间放到气泡外上方；随后指出第一版固定宽度元信息行仍很松散。本批最终取消元信息最小宽度，时间紧随姓名，自己的一组信息整体靠右，对方靠左。

## 变化与实测

- 三端会话路径填满导航下的可用视口，压缩页头、聊天头及输入区；不修改其它业务页的宽度。
- 头像使用姓名首字占位。正文14px，短气泡按内容收缩；姓名12px、时间11px，间距8px，不再拉开到固定行两端。当日显示时分，同年跨日显示月日及时分，跨年显示完整日期；悬停和datetime保留完整时间。
- 图片限尺寸缩略、原图预览和协议业务按钮保留；发送、权限、匿名和已读规则不变。
