# 一户多人：现有绑定方式与批准实施方案

> 用户2026-10-14要求实现一户多人。用户确认独立账号依赖主居住关系；主关系结束，所有依赖关系同步结束。新增共同居住人标签与原FAMILY并列。实际进度只见50中控。

## 1. 现在实际是什么

**没有“一个主账号挂多个附属账号”的模型。每个人都是独立居民账号。** 房屋信息通过居住关系关联，不存在账号表中。

| 数据 | 当前内容 |
|---|---|
| resident | 用户名、姓名、手机号、证件、邮箱、账号状态等，不存父账号ID或房屋归属 |
| residence_relation | resident_id、community_id、house_id、relation_type（OWNER/TENANT/FAMILY/CO_RESIDENT）、入住/迁出日期、is_primary、lease_id、anchor_relation_id；有效的居民-房屋组合唯一 |
| is_primary | **是否该居民的主要居住地**，不是户主、主承租人、父账号或同住关系的锚点；不能拿它推断主住户 |
| 租客关系 | 协议确认且首期支付成功后建立正式关系，并关联租约 |

原来只允许空置房直录，已入住房屋不能补另一人；本轮新增依赖主关系登记，FAMILY/CO_RESIDENT可在有效主关系所在已入住房屋登记。注册仍不等于入住，账号创建与关系登记明确分开。

事实依据：ResidenceRelation实体、V1/V32/V35关系表、ResidenceRelationService.adminCreate/moveOut、ResidenceApplicationService及30接口§9.2.4.5。

## 2. 已批准模型：同一房屋，独立账号，明确主关系

- OWNER或正式生效的TENANT关系作为同住登记的依据；待审核、待签约或未支付首期的租客不能登记同住成员。
- 同住成员保持独立账号，在该房屋新增自己的关系；增加明确的主关系引用，`anchor_relation_id`，不复用is_primary。
- 家属保留FAMILY；非亲属共同居住人使用单独的CO_RESIDENT标签，避免把所有人都叫家属。标签不改变租约义务。
- 主关系引用必须指向同一房屋、仍在住的OWNER/TENANT，不得指向另一名同住成员；不允许链式父子关系或跨房屋挂靠。
- 同一居民与同一房屋不得有重复有效关系；已有历史不删除，新增与迁出都留痕。
- 同住成员不新建租约，不成为第二个承租义务人，不继承租金、押金、退款或协议操作权限；租约义务仍属于原承租人。

不选择“附属账号/共用密码”，也不把成员列表塞进resident的JSON字段；继续使用既有账号与关系表，并补足关系锚点和生命周期。

## 3. 管理员实际怎么登记

管理端「居民管理 → 居住关系」增加“登记同住人员”：

1. 展示当前房屋、有效主关系、已经登记的成员。
2. 按完整用户名或手机号精确检索现有正常居民账号（不全库模糊列出），或代建账号并同时登记；填写家属/共同居住人与入住日期。
3. 保存时复核管理权限、主关系仍有效、同一房屋、日期、重复关系；账号和关系要么同时成功，要么一起回滚。
4. 同住成员独立登录后显示自己的房屋/社区信息，可按既有在住权限使用本人服务；不显示其他居民的私有工单、个人资料或交易信息。

CSV可在同一房屋编号下录多行，主关系唯一时服务端自动解析；不存在有效主关系或无法唯一确定时给具体失败原因，不让导入绕过限制。已有账号的绑定走登记入口，重复导入不得偷偷合并或替换账号。

首批只开放管理员审核登记，不让居民任意邀请成员直接取得私有权限。现有账号检索只返回登记所需最小资料，不开放跨社区住户详情。

## 4. 迁出闭环（用户确认）

| 操作 | 推荐行为 |
|---|---|
| 某位同住成员迁出 | 只结束本人的关系；不结束主租约、其他成员关系，不把房屋改为空置 |
| 主住户迁出/承租人退租 | 明确展示关联成员，二次确认后结束该主关系及其关联成员；不能静默留下孤立同住关系 |
| 未确认整户迁出 | 不提交迁出；需要保留某位成员时先由管理员明确重新登记其合法依据，不自动升为OWNER/TENANT |
| 房屋重新可申请 | 所有在住关系结束，且无待处理占用/有效租约后，才回空置并按已批准挂牌规则解除占用 |

所有关系迁出只记录日期/操作者，不删除账号或历史。办理整户退租须覆盖关系迁出、租约直接办理退租（列表/详情）和退租申请审核所有入口，不只改新增入口。日期不得早于本人入住日；同住登记不得早于主关系生效。

交易仍暂缓；通过非交易的OWNER主关系在隔离库验证多人登记，租客生效前拒绝和退租联动用单测验证。不能伪造支付成功来使正常库租客关系生效。

## 5. 必须回归什么

同户多账号、代建/已有账号登记、重复关系与CSV重复、越社区/越房屋/无有效主关系拒绝；成员只能访问自身私有业务；单人迁出不释放整户；整户确认迁出不留下成员或占用；租约/首期生效规则不被放宽；操作失败原子回滚。
