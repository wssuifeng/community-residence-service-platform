# 演示环境使用说明

## 1. 演示账号

当前演示种子提供以下账号，首次用于本地演示即可：

| 端 | 账号 | 密码 | 用途 |
|---|---|---|---|
| 超级管理员 | `superadmin` | `Admin@123456` | 全局配置、小区和权限管理 |
| 小区管理员 | `admin1` | `Admin123456` | 绑定小区内的日常管理和派单 |
| 服务人员 | `staff1` | `Staff123456` | 查看本人派单和处理工单 |
| 居民 | `resident1` | `Resident123456` | 居民首页、公告、工单、预约和租住信息 |

这些是开发演示凭据，云端或生产环境必须更换，并按部署环境重新注入密钥。

## 2. 本机入口

本机当前演示入口为 `http://localhost:18088`。后端OpenAPI为 `http://localhost:18080/swagger-ui.html`。端口保存在未入库的`.env.docker`中，默认值及修改方法见《本地容器化部署》。所有容器发布端口只绑定回环地址，不向局域网开放。

## 3. 推荐演示顺序

1. 未登录浏览公开公告、房源和可预约看房时段；看房预约需居民账号登录后提交。
2. 居民登录，查看首页、消息中心、个人中心，浏览公告和公共资源。
3. 小区管理员登录，查看小区、居民、工单和排班入口。
4. 服务人员登录，查看本人工作台和待处理工单。
5. 超级管理员登录，查看系统账号和全局管理入口。

演示以只读浏览为主，不执行真实支付、查单、退款或支付渠道配置操作。

## 4. 图片资源

图片由本机 `uploads/` 目录提供。图片目录不进入镜像、不提交 Git，也不会被 Compose 自动上传到云端。删除或更换本地图片只影响当前机器上的展示资源，不会改变数据库迁移结构。

## 5. 重置演示环境

优先使用 Compose 卷重置：

```powershell
docker compose --env-file .env.docker -f docker-compose.local.yml down -v
docker compose --env-file .env.docker -f docker-compose.local.yml up -d --build --wait
```

若使用本机 MySQL，则执行 `tools/demo/reset-demo-database.ps1`。重置前会生成本地备份，数据库重建后由 Flyway 恢复演示数据。

本次数据库与种子核验结果见[演示数据库清理记录](演示数据库清理记录-20261021.md)。
