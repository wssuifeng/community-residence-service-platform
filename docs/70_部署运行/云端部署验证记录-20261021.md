## 6. 收尾范围与运行边界

- 域名 DNS 和 HTTP 入口已完成；当前域名为 `cloud-computing-webstatic.cc.cd`。
- HTTPS 证书已申请并部署，443 已由 Nginx 监听，HTTP 已自动跳转 HTTPS。
- Certbot 自动续期定时器已启用；本次 `renew --dry-run` 因 ACME 测试服务长时间无输出而中止，未影响当前正式证书。
- 用户裁决：不建立云盘/数据库备份与恢复演练记录。原“备份恢复”是指将数据库导出和 `cloud_uploads` 卷复制到独立存储后进行恢复验证，不是部署上线所必需的数据库上传操作；本项目数据不重要，短期演示环境不执行。
- 用户裁决：不设置阿里云余额或费用告警。用户自行控制余额和使用时长，使用后主动停止 ECS。
- 该两项属于长期运行运维保障，不是本次毕业设计演示部署的阻塞项；本记录不把它们表述为系统缺陷或部署失败。
- ECS Docker 服务已设为 `enabled`，Compose 四服务均使用 `restart: unless-stopped`。正常停止并重新启动 ECS 后，Docker 会自动启动并恢复未被手动停止的容器；若曾执行 `docker compose stop` 或 `docker compose down`，需重新执行 `up -d --wait`。
- Let's Encrypt 自动续期依赖 ECS 在续期窗口内开机且域名与 `80/443` 入口可达；短期关机不影响当前证书，但长期关闭后重新开机时应检查证书有效期。
- 当前仍是学习和毕业设计演示环境，不按生产系统宣称高可用、灾备或安全合规。
