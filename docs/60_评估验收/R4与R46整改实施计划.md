# R4与R46整改实施计划

**目标**：按2026-10-20用户裁决收敛房屋状态、服务人员管理权限，并提供必须绑定授权社区的服务人员代建账号闭环。

**架构**：沿既有house、residence_relation、sys_user与staff_community模型实现；共享规则在common内保持一份，管理端协调入口在admin。后端负责权限与事务，前端只提供对应操作。

**技术栈**：Java 17 / Spring Boot 4 / MyBatis-Plus / MySQL Flyway；Vue 3 Composition API、TypeScript。

**约束**：本计划归60-03、G-006/G-007，既有C1/C2/C4/C10已实现依赖可用；用户已批准上游修订与执行。金融不复测，不改渠道；使用隔离环境验证写入；本批不触碰正常数据库。最终正常版本统一在剩余需求整改后加载；本地提交不推送。

## 工作一：固化上游与权限边界

1. 决策日志先登记用户裁决，沿系统定义v1.11→需求v1.23→30架构/数据库/接口/UI更新，术语表收编。本文件是后续实施和复验的统一规则入口。
2. R4：对外五状态为业主自住、租客居住、空置、维护中、停用。正式居住由有效主关系决定；临时占用与挂牌发布意愿独立。人工维护/停用不能覆盖在住或待处理占用；恢复遵守相同保护。既有租约首期成功规则不变。
3. R46/R65：社区管理员可代建STAFF、编辑本范围业务资料与绑定；无权查看系统账号完整详情、冻结全局账号、重置他人密码、创建ADMIN或改角色。多社区人员的外部绑定和类别必须保留。代建必选至少一个有效有权社区，账号与绑定共同提交或回滚。

## 工作二：服务人员闭环

1. 后端新增专用CreateStaffAccountDTO与管理入口POST /staff-capabilities/accounts，固定STAFF角色；复用SysUserService账号唯一性及密码编码；社区范围与启用校验先行，插入账号、社区、类别在外层同一事务。
2. StaffCapabilityService候选、列表、详情、保存只返回/更改ADMIN范围的社区及类别；对sys_user加行锁串行化人员绑定/排班/派单，保留他域绑定。业务资料更新仅姓名/电话/邮箱，角色及全局冻结权限不开放。
3. WorkOrderService.assign及assignable-staff、StaffScheduleService.batchSave验证绑定目标社区；看房带看人员选择检查共享范围。AdminSysUserController.getById限定超管。
4. 前端StaffCapabilityView编排列表与抽屉；新增StaffAccountCreateDialog接收visible/communities并emit created；新建STAFF表单含账号/密码/姓名/电话与必选社区，单一可用社区自动预选，多社区明确选择。人员编辑保留业务资料与能力绑定。系统账号页对STAFF导向服务人员子页，超管详情仍可访问。
5. 验证：有权代建成功并可登录；空社区/无权社区/停用社区/伪角色拒绝；绑定失败账号回滚；共同人员不覆盖外部绑定；未绑定目标社区的派单/排班拒绝；ADMIN完整详情403而业务详情正常。

## 工作三：房屋状态闭环

1. 对照ResidenceApplication/Relation、Lease/MoveOut、HousingOccupancy的既有锁顺序实施统一房屋状态规则，补Flyway新迁移，不改V1～V43。映射正式主关系与临时占用，保留历史变更含义。
2. 创建/编辑/批量生成只能设置空置、维护中、停用；业主/租客居住由关系产生。受影响读模型/筛选/统计/挂牌门控及前端图例统一，临时占用单列说明。
3. 验证业主登记/依赖成员/迁出、租客生效的代码边界（不发金融请求）、临时占用防重复、维护停用保护及恢复、所有创建与编辑入口不绕过。

## 工作四：固定版本与验收回写

1. JDK17定向单测、必要回归、前端类型/build及独立浏览器/API验证；测试证据按真实断言保存60/evidence，金融执行次数为0。
2. 隔离Flyway验证和固定Jar指纹后加载正常运行版本；记录源码、版本、迁移与可访问性，保留回退材料。
3. 更新需求逐条台账/差距/报告/中控/README/AGENTS及基线适用性。G-006/G-007已复验关闭；C9与E2/E3后续整改也已关闭G-001/G-002/G-004/G-005/G-008/G-014/G-017。当前仅G-015/N8浏览器矩阵证据不足，质量评估仍受整体验收门禁约束。
4. 检查差异、凭据/链接及文档一致性，选择性暂存本批文件，本地commit，不推送。
