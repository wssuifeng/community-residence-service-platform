# 70阶段部署运行交接清单 · 60阶段输出

> 本清单已作为70阶段部署输入使用。70阶段已于2026-10-21完成本地容器化、ECS云端Compose、域名HTTPS和部署级冒烟；其中费用告警及云端数据库/上传卷备份恢复演练按用户裁决不纳入本毕业设计演示环境。

> 本清单是60阶段向70阶段移交的验证输入，不表示70阶段已经启动或部署验收通过。所有需要真实部署目标、生产配置或多实例环境的项目，必须先固定环境和容量假设，再执行并保存可复核证据。

## 1. 前置条件

- 固定部署拓扑、操作系统/容器、JDK、MySQL、Redis、反向代理、静态资源托管方式和网络边界。
- 明确目标在线用户、注册账号、数据规模、峰值写入、文件量、消息量及可用性目标；未知容量下不预设连接池或超时参数。
- 记录部署版本、构建指纹、迁移版本、配置来源、密钥来源、运行账号和回滚目标。
- 正常开发库与用户浏览器不作为破坏性演练对象；演练须使用可恢复的隔离环境。
- 金融专项沿用户确认，不重复支付、查单、退款或渠道配置操作；若未来需要支付运维验证，先取得用户对具体场景的明确授权。

- 既有Redis故障测试已覆盖已记录的超时与恢复范围；历史约35.6秒长尾问题在修复后不再复现，最长约910.97ms。此结果不代表MySQL、上传、生产WebSocket、多实例或所有写入口均已覆盖。
