# 响应式布局设计规范

> 文档版本：v1.0  
> 创建日期：2026-09-07  
> 设计依据：UI设计.md（30 包）、组件库设计规范.md（30 包）

---

## 1. 概述

### 1.1 设计目标

为社区居住服务管理系统建立响应式布局规范，确保界面在不同设备上的可用性：
1. **主要适配**：桌面端（≥1200px），管理类系统的核心使用场景
2. **次要适配**：平板端（768px ~ 1199px），移动办公场景
3. **不适配**：移动端（<768px），提示用户使用桌面端（毕设范围外）

### 1.2 设计原则

1. **桌面优先**：设计从桌面端开始，向下适配平板端
2. **内容优先**：响应式调整优先保证内容可读性与操作可用性
3. **性能优先**：使用 CSS Grid/Flexbox 实现响应式，避免 JavaScript 计算布局
4. **渐进增强**：桌面端体验最佳，平板端功能完整但交互简化

### 2.3 JavaScript 断点检测

```typescript
// src/utils/responsive.ts
export const breakpoints = {
  xs: 0,
  sm: 576,
  md: 768,
  lg: 1024,
  xl: 1200,
  xxl: 1600
}

export function getCurrentBreakpoint(): keyof typeof breakpoints {
  const width = window.innerWidth
  
  if (width >= breakpoints.xxl) return 'xxl'
  if (width >= breakpoints.xl) return 'xl'
  if (width >= breakpoints.lg) return 'lg'
  if (width >= breakpoints.md) return 'md'
  if (width >= breakpoints.sm) return 'sm'
  return 'xs'
}

export function isDesktop(): boolean {
  return window.innerWidth >= breakpoints.xl
}

export function isTablet(): boolean {
  const width = window.innerWidth
  return width >= breakpoints.md && width < breakpoints.xl
}

export function isMobile(): boolean {
  return window.innerWidth < breakpoints.md
}
```

## 5. 响应式工具函数

### 5.1 Composable: useResponsive

```typescript
// src/composables/useResponsive.ts
import { ref, onMounted, onUnmounted } from 'vue'
import { getCurrentBreakpoint, isDesktop, isTablet, isMobile } from '@/utils/responsive'

export function useResponsive() {
  const breakpoint = ref(getCurrentBreakpoint())
  const desktop = ref(isDesktop())
  const tablet = ref(isTablet())
  const mobile = ref(isMobile())
  
  const updateBreakpoint = () => {
    breakpoint.value = getCurrentBreakpoint()
    desktop.value = isDesktop()
    tablet.value = isTablet()
    mobile.value = isMobile()
  }
  
  onMounted(() => {
    window.addEventListener('resize', updateBreakpoint)
  })
  
  onUnmounted(() => {
    window.removeEventListener('resize', updateBreakpoint)
  })
  
  return {
    breakpoint,
    isDesktop: desktop,
    isTablet: tablet,
    isMobile: mobile
  }
}
```

**使用示例**：
```vue
<script setup lang="ts">
import { useResponsive } from '@/composables/useResponsive'

const { isDesktop, isTablet, isMobile } = useResponsive()
</script>

<template>
  <div>
    <el-table-column v-if="isDesktop" prop="category" label="分类" />
    <el-button v-if="!isTablet" type="primary">批量操作</el-button>
    
    <div v-if="isMobile" class="mobile-not-supported">
      请使用桌面端访问
    </div>
  </div>
</template>
```

### 5.2 指令：v-responsive

```typescript
// src/directives/responsive.ts
import { Directive } from 'vue'
import { isDesktop, isTablet, isMobile } from '@/utils/responsive'

export const vResponsive: Directive = {
  mounted(el, binding) {
    const { value } = binding
    const shouldShow = checkVisibility(value)
    
    if (!shouldShow) {
      el.style.display = 'none'
    }
    
    const handleResize = () => {
      const shouldShow = checkVisibility(value)
      el.style.display = shouldShow ? '' : 'none'
    }
    
    window.addEventListener('resize', handleResize)
    el._handleResize = handleResize
  },
  
  unmounted(el) {
    window.removeEventListener('resize', el._handleResize)
  }
}

function checkVisibility(value: string): boolean {
  switch (value) {
    case 'desktop':
      return isDesktop()
    case 'tablet':
      return isTablet()
    case 'mobile':
      return isMobile()
    case 'desktop-tablet':
      return isDesktop() || isTablet()
    default:
      return true
  }
}
```

**使用示例**：
```vue
<template>
  <!-- 仅桌面端显示 -->
  <div v-responsive="'desktop'">
    桌面端内容
  </div>
  
  <!-- 桌面端 + 平板端显示 -->
  <div v-responsive="'desktop-tablet'">
    非移动端内容
  </div>
</template>
```

## 7. 性能优化策略

### 7.1 CSS Grid 优先

**优势**：
- 原生支持响应式布局
- 性能优于 JavaScript 计算
- 浏览器硬件加速

**示例**：
```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: var(--spacing-lg);
}
```

### 7.2 防抖 resize 事件

```typescript
import { debounce } from 'lodash-es'

const handleResize = debounce(() => {
  updateBreakpoint()
}, 200)

window.addEventListener('resize', handleResize)
```

### 7.3 条件加载组件
