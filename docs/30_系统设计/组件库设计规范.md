> 文档版本：v1.0  
> 创建日期：2026-09-07  
> 设计依据：UI设计.md（30 包）、架构设计.md（30 包）

---

## 1. 概述

### 1.1 设计目标

建立统一的组件设计规范，指导前端开发：
1. **组件分层**：明确通用组件（Element Plus）与业务组件（自写）的边界
2. **封装策略**：定义业务组件封装层，实现组件库可替换
3. **设计 Token**：统一间距、圆角、阴影、颜色等设计变量
4. **可访问性**：确保所有组件符合 WCAG 2.1 AA 级标准

### 1.2 组件策略

- **自写为主**：核心业务组件自行编写，保证美观与个性化
- **Element Plus 可用不依赖**：通用组件（表格/分页/弹窗/表单）可引用 Element Plus 加速开发，但经业务薄封装层引用
- **可整体替换**：架构上组件库可整体切换（Element Plus → Ant Design Vue），业务代码无需修改

## 2. 组件分层架构

```
┌─────────────────────────────────────────┐
│         业务页面（Views）                │
│   （居民端/服务人员端/管理端页面）        │
└────────────────┬────────────────────────┘
                 │ 依赖
┌────────────────▼────────────────────────┐
│       业务组件层（Business Components）   │
│   WorkOrderCard / FeedbackChat / ...    │
│        （自写，封装业务逻辑）              │
└────────────────┬────────────────────────┘
                 │ 依赖
┌────────────────▼────────────────────────┐
│       通用组件封装层（Wrapper Layer）     │
│    BaseTable / BaseForm / BaseDialog    │
│    （薄封装 Element Plus，可替换）        │
└────────────────┬────────────────────────┘
                 │ 依赖
┌────────────────▼────────────────────────┐
│      第三方组件库（Element Plus 2.14）    │
│   el-table / el-form / el-dialog / ...  │
└─────────────────────────────────────────┘
```

### 2.1 分层职责

| 层级 | 职责 | 示例 | 替换策略 |
|------|------|------|---------|
| 业务页面 | 页面布局 + 业务逻辑 + 状态管理 | `WorkOrderList.vue` | 不可替换 |
| 业务组件层 | 业务领域组件 + 数据转换 + 交互逻辑 | `WorkOrderCard.vue` | 不可替换 |
| 通用组件封装层 | 统一 API + 默认配置 + 样式覆盖 | `BaseTable.vue` | **可替换**（切换组件库时仅修改此层） |
| 第三方组件库 | 底层 UI 组件 | `el-table` | 可替换 |

## 3. 设计 Token 系统

### 3.1 间距系统（Spacing）

统一间距变量，避免硬编码：

```css
/* src/styles/variables.css */
:root {
  /* 间距 Token */
  --spacing-xs: 4px;     /* 极小间距（图标与文字） */
  --spacing-sm: 8px;     /* 小间距（表单字段间距） */
  --spacing-md: 16px;    /* 中等间距（卡片内边距） */
  --spacing-lg: 24px;    /* 大间距（模块间距） */
  --spacing-xl: 32px;    /* 极大间距（页面顶部间距） */
  --spacing-xxl: 48px;   /* 超大间距（页面分段间距） */
}
```

**使用规则**：
- 组件内边距（padding）：优先使用 `--spacing-md`（16px）
- 组件外边距（margin）：优先使用 `--spacing-lg`（24px）
- 表单字段间距：`--spacing-sm`（8px）
- 模块分段间距：`--spacing-xl`（32px）

---

### 3.2 圆角系统（Border Radius）

```css
:root {
  /* 圆角 Token */
  --radius-sm: 4px;      /* 小圆角（按钮/输入框） */
  --radius-md: 8px;      /* 中等圆角（卡片） */
  --radius-lg: 12px;     /* 大圆角（弹窗） */
  --radius-pill: 999px;  /* 胶囊（Tag/Badge） */
  --radius-circle: 50%;  /* 圆形（头像） */
}
```

**使用规则**：
- 按钮/输入框/下拉框：`--radius-sm`（4px）
- 卡片/面板：`--radius-md`（8px）
- 弹窗/抽屉：`--radius-lg`（12px）
- Tag/Badge/Chip：`--radius-pill`（999px）
- 头像/图标容器：`--radius-circle`（50%）

## 4. 通用组件封装层规范

### 4.1 封装原则

1. **统一 API**：所有封装组件提供一致的 Props/Events/Slots 接口
2. **默认配置**：预设合理的默认值，减少业务代码配置
3. **样式覆盖**：使用 CSS 变量覆盖 Element Plus 默认样式
4. **类型定义**：所有组件提供完整的 TypeScript 类型定义

---

### 4.2 BaseTable 封装示例

**功能**：封装 Element Plus Table，统一分页/排序/筛选逻辑

```vue
<!-- src/components/common/BaseTable.vue -->
<template>
  <div class="base-table">
    <el-table
      :data="data"
      :loading="loading"
      v-bind="$attrs"
      @sort-change="handleSortChange"
      @selection-change="handleSelectionChange"
    >
      <slot />
    </el-table>

    <el-pagination
      v-if="showPagination"
      :current-page="pagination.page"
      :page-size="pagination.size"
      :total="pagination.total"
      :page-sizes="[10, 20, 50, 100]"
      layout="total, sizes, prev, pager, next, jumper"
      @size-change="handleSizeChange"
      @current-change="handleCurrentChange"
    />
  </div>
</template>

<script setup lang="ts">
import { computed } from 'vue'

interface Props {
  data: any[]
  loading?: boolean
  pagination?: {
    page: number
    size: number
    total: number
  }
  showPagination?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  loading: false,
  pagination: () => ({ page: 1, size: 20, total: 0 }),
  showPagination: true
})

const emit = defineEmits<{
  sortChange: [{ prop: string; order: string }]
  selectionChange: [any[]]
  pageChange: [{ page: number; size: number }]
}>()

const handleSortChange = (sort: any) => {
  emit('sortChange', sort)
}

const handleSelectionChange = (selection: any[]) => {
  emit('selectionChange', selection)
}

const handleSizeChange = (size: number) => {
  emit('pageChange', { page: 1, size })
}

const handleCurrentChange = (page: number) => {
  emit('pageChange', { page, size: props.pagination.size })
}
</script>

<style scoped>
.base-table {
  width: 100%;
}

.el-pagination {
  margin-top: var(--spacing-lg);
  display: flex;
  justify-content: flex-end;
}
</style>
```

**使用示例**：

```vue
<!-- 业务页面中使用 -->
<template>
  <BaseTable
    :data="workOrders"
    :loading="loading"
    :pagination="pagination"
    @page-change="handlePageChange"
    @sort-change="handleSort"
  >
    <el-table-column prop="orderNo" label="工单号" width="180" />
    <el-table-column prop="title" label="标题" />
    <el-table-column prop="status" label="状态" width="120">
      <template #default="{ row }">
        <StatusTag :status="row.status" />
      </template>
    </el-table-column>
  </BaseTable>
</template>
```

### 4.3 BaseForm 封装示例

**功能**：封装 Element Plus Form，统一校验/提交逻辑

```vue
<!-- src/components/common/BaseForm.vue -->
<template>
  <el-form
    ref="formRef"
    :model="modelValue"
    :rules="rules"
    :label-width="labelWidth"
    v-bind="$attrs"
  >
    <slot />
    
    <el-form-item v-if="showActions">
      <el-button @click="handleCancel">取消</el-button>
      <el-button
        type="primary"
        :loading="submitLoading"
        @click="handleSubmit"
      >
        提交
      </el-button>
    </el-form-item>
  </el-form>
</template>

<script setup lang="ts">
import { ref } from 'vue'
import type { FormInstance, FormRules } from 'element-plus'

interface Props {
  modelValue: Record<string, any>
  rules?: FormRules
  labelWidth?: string
  showActions?: boolean
  submitLoading?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  labelWidth: '120px',
  showActions: true,
  submitLoading: false
})

const emit = defineEmits<{
  submit: [data: Record<string, any>]
  cancel: []
}>()

const formRef = ref<FormInstance>()

const handleSubmit = async () => {
  if (!formRef.value) return
  
  try {
    await formRef.value.validate()
    emit('submit', props.modelValue)
  } catch (error) {
    console.error('表单校验失败:', error)
  }
}

const handleCancel = () => {
  emit('cancel')
}

// 暴露方法供父组件调用
defineExpose({
  validate: () => formRef.value?.validate(),
  resetFields: () => formRef.value?.resetFields(),
  clearValidate: () => formRef.value?.clearValidate()
})
</script>
```

### 4.4 BaseDialog 封装示例

**功能**：封装 Element Plus Dialog，统一宽度/样式/关闭逻辑

```vue
<!-- src/components/common/BaseDialog.vue -->
<template>
  <el-dialog
    :model-value="modelValue"
    :title="title"
    :width="width"
    :close-on-click-modal="false"
    @update:model-value="emit('update:modelValue', $event)"
    @close="handleClose"
  >
    <slot />
    
    <template #footer v-if="showFooter">
      <slot name="footer">
        <el-button @click="handleCancel">取消</el-button>
        <el-button
          type="primary"
          :loading="confirmLoading"
          @click="handleConfirm"
        >
          确定
        </el-button>
      </slot>
    </template>
  </el-dialog>
</template>

<script setup lang="ts">
interface Props {
  modelValue: boolean
  title: string
  width?: string
  showFooter?: boolean
  confirmLoading?: boolean
}

const props = withDefaults(defineProps<Props>(), {
  width: '600px',
  showFooter: true,
  confirmLoading: false
})

const emit = defineEmits<{
  'update:modelValue': [value: boolean]
  confirm: []
  cancel: []
  close: []
}>()

const handleConfirm = () => {
  emit('confirm')
}

const handleCancel = () => {
  emit('cancel')
  emit('update:modelValue', false)
}

const handleClose = () => {
  emit('close')
}
</script>
```

## 6. 可访问性规范

### 6.1 键盘导航

- **Tab 键**：按顺序聚焦可交互元素（表单/按钮/链接）
- **Enter 键**：触发聚焦元素的默认操作（提交表单/点击按钮）
- **ESC 键**：关闭弹窗/抽屉
- **方向键**：在列表/表格中移动焦点

### 6.2 焦点指示

```css
/* 所有可交互元素的焦点样式 */
:focus-visible {
  outline: 2px solid var(--color-primary);
  outline-offset: 2px;
}

/* 移除浏览器默认焦点样式 */
:focus {
  outline: none;
}
```

### 6.3 语义化标签

- **表单**：使用 `<form>` + `<label>` + `<input>`
- **按钮**：使用 `<button>`，禁止用 `<div>` + `@click`
- **链接**：使用 `<a>`，禁止用 `<span>` + `@click`
- **标题**：使用 `<h1>` ~ `<h6>`，按层级使用

### 6.4 ARIA 属性

```html
<!-- 弹窗 -->
<div role="dialog" aria-labelledby="dialog-title" aria-modal="true">
  <h2 id="dialog-title">创建工单</h2>
  <!-- 内容 -->
</div>

<!-- 按钮 -->
<button aria-label="关闭弹窗">
  <i class="icon-close"></i>
</button>

<!-- 加载中 -->
<div aria-live="polite" aria-busy="true">
  加载中...
</div>
```

### 6.5 对比度

- **正文文字**：与背景对比度 ≥ 4.5:1（WCAG AA 级）
- **大号文字**（≥18px 或 ≥14px 加粗）：对比度 ≥ 3:1
- **非文本元素**（图标/边框）：对比度 ≥ 3:1

## 7. 组件替换指南

### 7.1 替换场景

**场景**：从 Element Plus 切换到 Ant Design Vue

### 7.2 替换步骤

1. **修改通用组件封装层**（`src/components/common/`）：
   - `BaseTable.vue`：`el-table` → `a-table`
   - `BaseForm.vue`：`el-form` → `a-form`
   - `BaseDialog.vue`：`el-dialog` → `a-modal`

2. **保持业务组件不变**：
   - 业务组件（`src/components/business/`）不依赖组件库，无需修改

3. **更新全局样式**：
   - 修改 `src/styles/variables.css` 中的 Token 值（圆角/阴影/间距）

4. **测试验收**：
   - 运行 `npm run test` 确保所有组件测试通过
   - 手动测试所有页面，确认样式与交互一致
