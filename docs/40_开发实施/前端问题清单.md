## 1. 已修复的前端缺陷（当轮修复当轮验证）

### 问题1：楼栋创建 400「参数[floors]楼层数不能为空」
**页面**：/admin/buildings　**优先级**：P0（E1 阻塞）
**根因**：接口文档 9.1.2.1 请求体 `totalFloors`，后端 CreateBuildingDTO 为 `floors`。
**修复**：types/modules/community.ts + BuildingListView + CommunityDetailView。

### 问题2：单元创建字段全错
**页面**：/admin/units　**优先级**：P0（E1 阻塞）
**根因**：文档 `unitNumber/totalFloors/householdsPerFloor`，后端 CreateUnitDTO 仅 `buildingId/name/description`。
**修复**：types + UnitListView（表单与表格列重做）。

### 问题3：房屋创建字段漂移
**页面**：/admin/houses　**优先级**：P0（E1 阻塞）
**根因**：文档 `bedrooms/livingRooms/bathrooms/propertyType`，后端 CreateHouseDTO 为 `roomCount/layout`（无属性类型/月租金）。
**修复**：types + HouseListView（户型改文本输入 + 房间数，去属性/月租金列）。

### 问题4：admin1 公告存草稿失败「社区管理员必须指定目标社区」
**页面**：/admin/notices/create　**优先级**：P0（E5 阻塞）
**根因**：登录响应 `boundCommunities` 文档为 `[{communityId, communityName}]`，后端实际返回纯 ID 数组 `[1]`——表单默认社区取 `.communityId` 落空。
**修复**：types/user.ts 改 `number[]`；NoticeCreateView 经社区列表接口补名并默认选中；ServiceCategoryListView 取值方式同步修正。

### 问题5：居民提交工单 400「参数[content]工单内容不能为空」
**页面**：/resident/work-orders/create　**优先级**：P0（E4 阻塞）
**根因**：文档 `description/urgency`，后端 CreateWorkOrderDTO 为 `content/priority`（另有 address，无 appointmentTime）；WorkOrderVO 用 `orderNo`，且无各时间戳/驳回取消原因字段。
**修复**：workorder types + 居民/管理/服务人员 8 个视图全量适配。

### 问题6：反馈办结 400「参数[remark]办结说明不能为空」
**页面**：/admin/feedbacks/:id　**优先级**：P1（E6 阻塞）
**根因**：文档 `reason`，后端 CloseFeedbackDTO 为 `remark`。
**修复**：FeedbackCloseDTO + FeedbackDetailView。

### 问题7：公告发布 500（时间格式）
**页面**：/admin/notices（发布按钮）　**优先级**：P1（E5 阻塞）
**根因**：前端 `new Date().toISOString()` 产出带 Z 后缀 ISO，后端 Jackson 不解析带时区格式（无 Z 则 200）——后端问题，前端绕过。
**修复**：3 处视图统一转本地无时区格式 `toLocalIso()`；后端侧登记 BE-ISSUE-6。

### 问题8：看房预约/评价模型整体漂移
**页面**：/resident/housings/:id、/admin/viewing-appointments、/resident/work-orders/:id、/admin/evaluations　**优先级**：P0（E10b/E8 阻塞）
**根因**：①看房预约文档 `timeslotId` 直传，后端要 `appointmentDate+startTime+endTime+contactPhone`；②看房状态机文档 `PENDING/CONFIRMED`，后端（状态机权威口径）`TO_CONFIRM/RESERVED`；③房源时段文档按日期模型（date/maxBookings），后端为周循环模板（dayOfWeek/isAvailable）；④评价文档 4 维评分，后端单维 `rating+tags+isSatisfied`。
**修复**：housing/evaluation types + 5 视图；available-slots 404 时降级用周模板前端展开。

## 4. P2 前端实施补记（2026-09-09）

### 问题9：BaseUploader 上传契约偏差（P0，T2 文件上传阻塞）
**组件**：components/common/BaseUploader.vue　**发现时机**：P2 T2 联调
**根因**：组件读 `result.url`，后端 UploadResult 实际字段为 `fileUrl`；且未传
`type` 参数（后端默认 IMAGE，文档类 pdf/doc/docx 一律被拒）。另
ImageUploader accept 含 webp（后端不支持）、FileUploader 缺 txt。
**修复**：新建 `api/upload.ts` + `types/modules/upload.ts`（uploadFile 携
type），BaseUploader 改走 uploadFile 读 fileUrl；两子组件对齐后端允许的
扩展名。冒烟：IMAGE 200 / 静态访问 200 / type 不符 400（预期拒绝）。
