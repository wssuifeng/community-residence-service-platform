# 前后端联调测试提示词

**测试会话**：主会话（联调协调）  
**测试范围**：前后端联调测试（12 个 E2E 业务流程）  
**测试计划**：`docs/40_开发实施/P1核心功能测试计划.md` §4 前后端联调测试计划

---

## 提示词

```
你好，我需要你执行 P1 阶段的前后端联调测试。

【测试目标】
验证前后端接口对接正确、数据流转正常、端到端业务流程完整可用。

【测试计划】
请阅读测试计划文档：docs/40_开发实施/P1核心功能测试计划.md 的第 4 章"前后端联调测试计划"。

【测试范围】
执行以下 12 个端到端业务流程测试（E2E）：
- E1：社区初始化流程（超管创建社区/楼栋/单元/房屋）
- E2：居民注册与入住申请流程（注册→申请→审核→自动建立居住关系与租约）
- E3：租住管理流程（查询租约、状态判定、提前终止）
- E4：工单全流程（提交→派单→接单→处理→确认→评价，6 次状态流转）
- E5：公告发布与查看流程（创建→发布→查看→记录回执→下线）
- E6：反馈提交与会话流程（提交→回复自动受理→双向会话→办结）
- E7：资源预约流程（创建→审核→冲突检测→完成/取消）
- E8：服务评价流程（评价→不满意跟进→统计查询）
- E9：社区运营统计查看（16 卡片 + 4 图表，数据权限过滤）
- E10b：游客看房预约流程（未登录浏览房源→创建看房预约→审核）
- E11：消息与通知流程（派单/回复触发通知→查看→标记已读→增量拉取）
- E12：房源展示流程（筛选→查看详情→浏览统计→上下架）

【前置条件】
1. 后端应用已启动（http://localhost:8080）
2. 前端应用已启动（http://localhost:5173）
3. MySQL 和 Redis 已启动
4. Flyway 迁移已执行（V1~V5）
5. 测试账号已创建：
   - 超管：superadmin / Admin@123456
   - 管理员：admin1 / Admin123456（绑定社区 1）
   - 服务人员：staff1 / Staff123456（绑定社区 1）
   - 居民：resident1 / Resident123456（已入住社区 1）

【执行要求】
1. 按测试计划第 4.3 节的测试步骤逐项执行
2. 使用浏览器访问前端页面进行操作
3. 使用 Chrome DevTools Network 监控前后端请求
4. 验证每个流程的预期结果与验证点
5. 记录测试结果（通过/失败）
6. 发现缺陷时，记录缺陷详情（按测试计划第 6.2 节模板）
7. 执行接口对接验证（第 4.4 节）：路径一致性、响应格式、错误处理
8. 执行数据一致性验证（第 4.5 节）：创建后立即查询、数据库数据一致性

【测试报告】
测试完成后，更新测试计划文档第 7 章"测试报告"：
- 记录测试执行总结（测试周期、通过率）
- 记录缺陷统计（按等级、按模块）
- 给出测试结论（通过/不通过）
- 提出风险与建议

【注意事项】
- 优先执行 P0/P1 级别的核心流程（E2/E4/E6/E7）
- 发现 Blocker/Critical 级别缺陷时，立即停止测试并报告
- 数据级权限过滤是重点验证项（管理员仅看绑定社区数据）
- 状态机流转是重点验证项（6 个状态机的合法/非法流转）

请开始执行联调测试，并实时报告测试进展。
```

---

**使用说明**：
1. 确保前后端应用都已启动
2. 复制上述提示词发送给主会话 AI
3. AI 将协调前后端测试，执行 E2E 流程
4. 测试完成后查看测试报告
