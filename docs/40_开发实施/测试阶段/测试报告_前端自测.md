| 编号 | 等级 | 描述 | 根因 | 修复 |
|------|------|------|------|------|
| FE-BUG-1 | P1 | 登录失败（错误密码/冻结账号）无任何提示，控制台 Unhandled error | LoginView/RegisterView 只有 try/finally 缺 catch | 两视图补 catch + ElMessage.error（LoginView.vue / RegisterView.vue） |
| FE-BUG-2 | P1 | 全局配置页空白：列表数据不渲染 | 前后端契约不一致——接口文档 9.2.4.2 为分页 + key/value，后端实现为全量数组 + configKey/configValue | 类型（ISysConfig/IConfigValueResult）+ API（getConfigList）+ GlobalConfigView 全链路对齐后端 |
| FE-BUG-3 | P1 | 运营看板等 5 个统计页白屏（reading 'totalResidents'/'total'） | 接口文档 9.9.1 为嵌套 summary/trend 结构，后端实现为扁平 Map（workOrderTotal/byStatus 等） | 重写 types/modules/statistics + api/statistics + 4 个统计视图（Dashboard/WorkOrder/Resident/Evaluation），对齐后端扁平契约；后端无 /statistics/evaluations 独立端点，评价统计复用看板数据 |

## 4. 各测试项结果明细

### 4.1 公开页面渲染（5/5 通过）
游客首页（hero + 房源卡 + 公告摘要 + 注册引导）、房源列表、公告列表、登录页、注册页均正常渲染，无控制台错误。

### 4.2 表单校验（2/2 通过）
- 登录空表单提交 → warning 提示「请输入用户名和密码」
- 注册空表单提交 → warning 提示首个必填校验

### 4.3 路由守卫（6/6 通过）
- 未登录访问 /resident/home、/staff/dashboard、/admin/* → 全部重定向 `/auth/login?redirect=原路径`
- 登录后访问 /auth/login → 按角色跳转对应首页（RESIDENT/STAFF 验证通过）
- RESIDENT 访问 /admin/* → 403；STAFF 访问 /resident/* → 403

### 4.4 权限指令（4/4 通过）
- 超管：新建社区按钮可见、系统用户管理操作可见、全局配置编辑可见
- 管理员（角色变异模拟）：新建社区按钮隐藏（v-permission 移除 DOM）、管理端通用按钮（新建楼栋）仍可见

### 4.5 响应式布局（4/4 通过）
游客房源网格：1440px→4 列 / 1200px→4 列（auto-fill 自适应）/ 900px→2 列 / 600px→1 列，无布局破碎。

### 4.6 页面渲染扫描（64/64 通过）
全部功能路由加载后无 pageerror（Vue 渲染异常）；管理端各列表页在有数据时正常渲染表格与状态标签。
