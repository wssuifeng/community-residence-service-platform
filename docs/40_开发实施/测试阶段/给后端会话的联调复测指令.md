> **本版修正说明**（2026-09-09，后端会话依据实际代码逐端点核实后重写）：
> 上一版指令存在大量路径/字段/状态链错误（与实际 API 漂移），按原样执行会导致
> 多数流程假失败。本版所有路径、DTO 字段、预期状态均以**实际代码 + swagger-ui +
> 架构设计 §6 状态机**为准核实过。主要修正：

> - 测试库为 `community_residence_test`（非 residence_dev）；时段表为
>   `resource_timeslot`/`housing_timeslot`（周循环模板，非 time_slot_template）
> - E1 三级资源为平铺路径（POST /buildings、/units、/houses，父 ID 在请求体）
> - E3 续租 DTO 为 `newEndDate/monthlyRent/deposit`（止期顺延，非按月数）

> - E8 追评（followup）是管理员对不满意评价的跟进接口，居民不可用；居民评价后

> - E10 看房预约端点为 `/viewing-appointments`；初始状态 TO_CONFIRM，审批通过为
>   RESERVED（端点 `PATCH /{id}/confirm`）

**测试目标**：居民提交→派单→接单→处理→完成→居民确认

```bash

  -H "Authorization: Bearer $STAFF1_TOKEN" -H "Content-Type: application/json" \

  -H "Authorization: Bearer $STAFF1_TOKEN" -H "Content-Type: application/json" \
  -d '{"remark":"replaced faucet"}' | grep -q '"code":200' && echo "✓ 处理成功"

# 5. 完成工单（→ TO_CONFIRM 待居民确认）
curl -s -X PATCH "${BASE_URL}/work-orders/${WORKORDER_ID}/complete" \
  -H "Authorization: Bearer $STAFF1_TOKEN" -H "Content-Type: application/json" \

# 6. 居民确认（TO_CONFIRM → COMPLETED；无 CONFIRMED 状态）
curl -s -X PATCH "${BASE_URL}/work-orders/${WORKORDER_ID}/confirm" \
  -H "Authorization: Bearer $RESIDENT1_TOKEN" -H "Content-Type: application/json" \

  -H "Authorization: Bearer $RESIDENT1_TOKEN" | grep -q '"code":200' && echo "✓ 时间线可查"
```

**预期结果**：6 步全部 200；状态流转 PENDING→ASSIGNED→ACCEPTED→IN_PROGRESS→TO_CONFIRM→COMPLETED；时间线可查。

### E7：资源预约流程

**测试目标**：创建资源→配置时段模板→居民预约→取消

```bash
# 1. 超管创建公共资源（字段 type/location/capacity；无 requiresApproval 等字段）

RESOURCE_ID=$(curl -s -X POST "${BASE_URL}/resources" \

  curl -s -X POST "${BASE_URL}/resources/${RESOURCE_ID}/timeslots" \
    -H "Authorization: Bearer $SUPER_TOKEN" -H "Content-Type: application/json" \
    -d "{\"dayOfWeek\":${DOW},\"startTime\":\"09:00\",\"endTime\":\"21:00\"}" | grep -q '"code":200'
done && echo "✓ 时段模板已配置"

# 3. 居民创建预约（POST /resource-reservations；contactPhone 必填，无 participantCount）
TOMORROW=$(date -d "+1 day" +%Y-%m-%d)
# resv.json: {"resourceId":${RESOURCE_ID},"reserveDate":"${TOMORROW}","startTime":"10:00","endTime":"12:00","purpose":"play badminton","contactPhone":"13900000003"}
RESERVATION_ID=$(curl -s -X POST "${BASE_URL}/resource-reservations" \
  -H "Authorization: Bearer $RESIDENT1_TOKEN" -H "Content-Type: application/json" \
  --data-binary @resv.json | grep -o '"id":[0-9]*' | head -1 | cut -d':' -f2)

# 4. 查询预约详情（初始待审核）
curl -s "${BASE_URL}/resource-reservations/${RESERVATION_ID}" \
  -H "Authorization: Bearer $RESIDENT1_TOKEN" \
  | grep -q '"status":"PENDING"' && echo "✓ 预约状态: PENDING"

# 5. 边界校验：同日重复预约应被拒（5002）
curl -s -X POST "${BASE_URL}/resource-reservations" \
  -H "Authorization: Bearer $RESIDENT1_TOKEN" -H "Content-Type: application/json" \
  --data-binary @resv.json | grep -q '"code":5002' && echo "✓ 重复预约被拒"

# 6. 居民取消预约（PATCH /cancel 必须带请求体，reason 必填——空 body 会 400）
```
