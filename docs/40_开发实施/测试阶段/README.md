## ❓ 常见问题

### Q1: 测试账号登录后令牌过期怎么办？
**A**: JWT令牌有效期2小时，过期后需要重新登录获取新令牌。前端应实现令牌刷新机制。

### Q2: 跨社区测试为什么失败？
**A**: 数据级权限设计正确。admin1绑定社区1，无法访问社区3数据。使用超管或为每个社区创建专属管理员。

### Q3: 为什么部分接口返回404？
**A**: 统计、消息通知功能在P1阶段尚未实现，需要后端补充。

### Q4: DTO字段与文档不一致怎么办？
**A**: 以实际后端代码为准。已记录15处差异，前端需要适配。详见后端问题修复清单第六节。

### Q5: 资源预约为什么失败？
**A**: 需要管理员预先为资源配置可预约时段模板。这是业务设计，不是bug。
