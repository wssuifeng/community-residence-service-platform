### 2.3 JSON 请求体编码问题
**问题描述**：bash -d 参数传递 JSON 时会被 bash 转义，导致后端解析失败  
**影响范围**：所有 POST/PATCH 接口  
**解决方案**：使用临时文件 + `--data-binary @file` 发送请求

**错误示例**：
```bash
curl -d '{"name":"测试"}' # 400 请求体格式不合法
```

**正确示例**：
```bash
cat > /tmp/data.json << 'EOF'
{"name":"测试"}
EOF
curl --data-binary @/tmp/data.json
```

|------------|-------------|------|------|

| `totalUnits` | 无此字段 | POST /api/v1/buildings | 已忽略 |
