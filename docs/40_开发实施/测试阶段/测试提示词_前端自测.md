# 前端自测提示词

**测试会话**：前端工作区会话  
**测试范围**：前端自测（64 个页面、权限指令、路由守卫、响应式布局）  
**测试计划**：`docs/40_开发实施/P1核心功能测试计划.md` §3 前端自测计划

---

## 提示词

```
你好，我需要你执行 P1 阶段的前端自测。

【测试目标】
验证所有前端页面渲染正常、交互功能正确、权限指令生效、路由守卫正确拦截、表单校验有效、响应式布局适配。

【测试计划】
请阅读测试计划文档：docs/40_开发实施/P1核心功能测试计划.md 的第 3 章"前端自测计划"。

【前置条件 - 必须先完成】
1. 启动前端开发服务器：
   ```bash
   cd frontend
   npm run dev
   ```
2. 确认服务器启动成功（http://localhost:5173）
3. 准备 Mock 数据或对接后端测试环境（推荐对接后端）

【测试范围】
执行以下测试项（共 200+ 个测试用例）：

**1. 登录/注册页面**（FE-AUTH-001 ~ FE-AUTH-010）
- 访问登录页面
- 管理员/居民登录成功/失败
- 表单校验（用户名/密码为空）
- 居民注册（开关开启/关闭）

**2. 居民端页面**（FE-RESIDENT-001 ~ FE-RESIDENT-027）
- 首页、个人中心、工单管理、反馈管理、资源预约、公告管理、房源管理、看房预约、通知中心
- 重点：工单提交、反馈会话、预约创建、公告查看回执

**3. 服务人员端页面**（FE-STAFF-001 ~ FE-STAFF-006）
- 工作台、工单列表、工单详情、接单、处理工单

**4. 管理端页面**（FE-ADMIN-001 ~ FE-ADMIN-071）
- 运营看板（16 卡片 + 4 图表）
- 社区/楼栋/单元/房屋/公共资源管理
- 居民/租住/工单/公告/反馈/预约/评价/统计/权限/通知/房源管理
- 重点：超管专属按钮（创建社区、创建管理员、全局配置）显隐验证

**5. 游客端页面**（FE-GUEST-001 ~ FE-GUEST-006）
- 首页、房源浏览、公告浏览、看房预约（填写姓名/电话）

**6. 权限指令验证**（FE-PERM-001 ~ FE-PERM-004）
- 超管登录：验证超管专属按钮显示
- 管理员登录：验证超管专属按钮隐藏
- 管理员登录：验证管理端通用按钮显示
- 居民登录：验证管理端页面不可访问

**7. 路由守卫验证**（FE-ROUTE-001 ~ FE-ROUTE-005）
- 未登录访问受限页面 → 跳转登录页
- 登录后自动跳转回原页面
- 角色首页重定向（居民/管理员/服务人员）
- 角色不匹配 → 跳转 403

**8. 响应式布局验证**（FE-RESPONSIVE-001 ~ FE-RESPONSIVE-007）
- 桌面端（≥1280px）：4 列卡片、2 列图表
- 平板横屏（1024px~1280px）：3 列卡片、2 列图表
- 平板竖屏（768px~1024px）：2 列卡片、1 列图表
- 移动端（<768px，可选）：1 列卡片、1 列图表

**9. 表单校验验证**（FE-FORM-001 ~ FE-FORM-005）
- 必填字段为空、手机号/邮箱格式错误、日期范围错误、数字范围错误

【执行步骤】
1. **启动前端应用**：`cd frontend && npm run dev`
2. 打开浏览器访问 http://localhost:5173
3. 按测试计划第 3.3 节的测试用例逐项执行
4. 使用 Chrome DevTools 查看控制台日志（无错误）
5. 使用 Vue DevTools 查看组件状态（可选）
6. 记录测试结果（通过/失败）
7. 发现缺陷时，记录缺陷详情

【测试数据】
- 超管账号：superadmin / Admin@123456
- 管理员账号：admin1 / Admin123456
- 服务人员账号：staff1 / Staff123456
- 居民账号：resident1 / Resident123456

【测试报告】
测试完成后，记录以下内容：
1. 测试执行总结（测试用例总数、通过数、失败数、通过率）
2. 缺陷统计（按等级、按页面）
3. 重点验证项结果：
   - 权限指令验证：65 处 v-permission 是否生效
   - 路由守卫验证：是否正确拦截无权限访问
   - 响应式布局：4 个断点是否正常显示
4. 控制台错误统计（TypeScript 类型错误、网络请求失败）

【通过标准】
- [ ] 所有页面渲染正常，无白屏/错误
- [ ] 所有按钮点击有响应，无失效
- [ ] 所有表单提交成功，校验生效
- [ ] 所有路由跳转正常，守卫生效
- [ ] 权限指令正确隐藏无权限元素（65 处验证通过）
- [ ] 响应式布局在不同断点下正常显示
- [ ] 无 Console 错误（TypeScript 类型错误/网络请求失败）

【注意事项】
- **必须先启动前端应用**，确认可访问后再开始测试
- 优先测试核心页面（工单、反馈、预约、入住申请、租约）
- 重点验证权限指令（超管专属按钮在管理员登录时必须隐藏）
- 发现 P0/P1 级别缺陷时，立即记录并修复
- 可使用浏览器无痕模式模拟未登录状态

请先启动前端应用，然后开始执行前端自测，并实时报告测试进展。
```

---

**使用说明**：
1. 在前端工作区会话中使用此提示词
2. 复制上述提示词发送给前端会话 AI
3. AI 将启动前端应用并执行自测
4. 测试完成后查看测试报告
