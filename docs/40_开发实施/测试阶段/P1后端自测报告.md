## 3. 口径内偏差（3 项，非缺陷）

1. **BE-C1-009/010/018**：测试计划允许「403 或业务异常」。实际行为：数据级权限拦截器
   对 ADMIN 注入绑定社区条件后，非绑定社区数据不可见（404/空集），不泄露资源存在性，
   属正确的安全语义。
2. **BE-C10-006/007/008**（旧令牌吊销后访问）：测试计划预期 401，实际返回 403。
   令牌吊销后请求以匿名身份到达受保护端点，Spring Security 匿名 + 无权限场景标准
   返回 403（accessDeniedHandler）。核心断言「旧令牌立即失效」全部成立。
3. **BE-C2-001b**（重复注册）：测试计划措辞 409，实际按统一业务异常设计返回
   HTTP 200 + 业务码 5002（GlobalExceptionHandler 规范），符合接口设计.md §3。
