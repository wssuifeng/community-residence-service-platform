- 接口：`GET /api/v1/feedbacks/{id}/attachments`
- 现象：返回 404
- 影响：反馈详情页附件区显示为空
- 来源：前端测试报告 §3 BE-ISSUE-2

**排查方向**：
1. 检查 `FeedbackController` 是否有该端点的 `@GetMapping`
2. 对比接口设计文档 §9.6.2.3 定义的路径
3. 可能原因：
   - 端点未实现
   - 路径拼写错误（如 `/attachment` vs `/attachments`）
   - RequestMapping 路径配置错误

**修复步骤**：
1. 打开 Swagger UI：`http://localhost:8080/swagger-ui.html`
2. 搜索 `feedbacks` 相关端点
3. 确认是否存在 `GET /api/v1/feedbacks/{id}/attachments`
4. 如果不存在：
   - 在 `FeedbackController` 添加该端点
   - 或修复路径拼写错误
5. 如果存在但 404：检查路径参数映射（`@PathVariable`）

**预期响应**：

### 2.3 BE-ISSUE-3：游客公告回执权限拒绝（P1 Major）

**问题描述**：
- 接口：`POST /api/v1/notices/{id}/view`
- 现象：游客访问返回 403
- 影响：游客查看公告详情无法记录查看回执
- 矛盾：接口设计文档 §9.5.1.x 标注「记录查看（公开）」
- 来源：前端测试报告 §3 BE-ISSUE-3

**排查方向**：
1. 检查 `NoticeController` 的 `@PreAuthorize` 注解
2. 确认设计意图：游客是否需要记录公告查看回执？
   - 如果需要：放行权限或改为匿名记录
   - 如果不需要：通知前端移除游客端调用逻辑

**修复方案 A**（游客需要记录回执）：
```java
@PostMapping("/{id}/view")
@Operation(summary = "记录公告查看")
public Result<Void> recordView(@PathVariable Long id) {
    // 获取当前用户（可能为匿名）
    Long userId = SecurityUtils.getUserIdOrNull();
    noticeService.recordView(id, userId);
    return Result.success();
}
```

在 `SecurityConfig` 中放行该路径：
```java
.requestMatchers("/api/v1/notices/*/view").permitAll()
```

**修复方案 B**（游客不需要记录回执）：
- 保持 403 响应
- 通知前端移除游客端调用逻辑

**验证方式**：
- 未登录访问：`POST /api/v1/notices/1/view`
- 预期返回：200（方案 A）或 403（方案 B）

**优先级**：P1（需要澄清设计意图）

## 3. 后端测试遗留事项（非阻塞）

### 3.1 操作日志 AOP 切面实现（P2）

**现状**：
- 操作日志查询接口已实现（BE-C10-011 验证通过）
- 操作日志 AOP 写入切面未实现（归 P2 阶段）

**实现方案**：
```java
@Aspect
@Component
@Slf4j
public class OperationLogAspect {
    
    @Autowired
    private OperationLogService operationLogService;
    
    @Around("@annotation(operationLog)")
    public Object logOperation(ProceedingJoinPoint joinPoint, OperationLog operationLog) throws Throwable {
        // 记录操作前信息
        String username = SecurityUtils.getCurrentUsername();
        String ip = RequestUtils.getClientIp();
        String uri = RequestUtils.getRequestUri();
        String method = joinPoint.getSignature().getName();
        
        long startTime = System.currentTimeMillis();
        Object result = null;
        Exception exception = null;
        
        try {
            result = joinPoint.proceed();
            return result;
        } catch (Exception e) {
            exception = e;
            throw e;
        } finally {
            long duration = System.currentTimeMillis() - startTime;
            
            // 异步记录操作日志
            operationLogService.recordLog(
                operationLog.module(),
                operationLog.operation(),
                username,
                ip,
                uri,
                method,
                duration,
                exception == null ? "SUCCESS" : "FAILED",
                exception != null ? exception.getMessage() : null
            );
        }
    }
}
```

**优先级**：P2（不阻塞联调测试）
