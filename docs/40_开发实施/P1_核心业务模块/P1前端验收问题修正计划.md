## 2. 问题详情与修正方案

### 2.1 FE-V1：权限指令使用严重不足 🔴

**问题描述**：
- 全局搜索仅发现 **1 处** `v-permission` 使用
- 实施计划 §3.5 要求管理端所有 CRUD 操作按钮必须添加权限指令
- 预期使用场景：创建社区（限超管）、删除操作（限管理员）、全局配置（限超管）等

**验收标准引用**：
> §6.3 权限控制验收：权限指令正确隐藏按钮（v-permission）

**影响评估**：
- **功能风险**：无权限用户可见不应看到的按钮，点击后被后端拒绝（体验差）
- **验收阻塞**：不满足 §6.3 验收标准，无法通过验收

**修正方案**：

#### 2.1.1 需要添加权限指令的位置

**管理端 - C1 社区管理**：
```vue
<!-- CommunityListView.vue -->
<el-button v-permission="['SUPER_ADMIN']" type="primary" @click="handleCreate">
  创建社区
</el-button>

<!-- BuildingListView.vue / UnitListView.vue / HouseListView.vue -->
<el-button v-permission="['ADMIN', 'SUPER_ADMIN']" type="danger" @click="handleDelete(row)">
  删除
</el-button>
```

**管理端 - C10 权限管理**：
```vue
<!-- SysUserListView.vue -->
<el-button v-permission="['SUPER_ADMIN']" type="primary" @click="handleCreate">
  创建管理员
</el-button>

<!-- GlobalConfigView.vue -->
<div v-permission="['SUPER_ADMIN']">
  <!-- 整个全局配置页面限超管 -->
</div>
```

**管理端 - C5 公告管理**：
```vue
<!-- NoticeListView.vue -->
<el-button v-permission="['ADMIN', 'SUPER_ADMIN']" type="primary" @click="handleCreate">
  创建公告
</el-button>
<el-button v-permission="['ADMIN', 'SUPER_ADMIN']" type="danger" @click="handleWithdraw(row)">
  下线
</el-button>
```

**管理端 - 其他模块**（C2/C3/C4/C6/C7/C12）：
```vue
<!-- 所有列表页的创建按钮 -->
<el-button v-permission="['ADMIN', 'SUPER_ADMIN']" type="primary" @click="handleCreate">
  创建/新建
</el-button>

<!-- 所有列表页的删除按钮 -->
<el-button v-permission="['ADMIN', 'SUPER_ADMIN']" type="danger" @click="handleDelete(row)">
  删除
</el-button>
```

### 2.2 FE-V2：页面数量不匹配 🟡

**问题描述**：
- 实施计划预期：64 个页面（居民端 16 + 游客端 6 + 服务人员端 4 + 管理端 38）
- 实际统计：66 个页面（居民端 17 + 游客端 6 + 服务人员端 5 + 管理端 38）
- 多出 2 个页面：居民端 +1，服务人员端 +1

**修正方案**：

#### 2.2.1 排查额外页面

执行以下命令确认：
```bash
cd frontend
find src/views/resident -name "*.vue" -exec basename {} \; | sort
find src/views/staff -name "*.vue" -exec basename {} \; | sort
```

对比实施计划 §4 模块清单，找出多余页面。

#### 2.2.2 处理方式

**场景 A**：额外页面是 404/403 错误页
- 结论：合理，无需删除
- 更新实施计划页面数量为 66

**场景 B**：额外页面是功能重复
- 删除多余页面
- 更新路由配置

**场景 C**：额外页面是新增需求
- 确认是否属于 P1 范围
- 更新实施计划
