**如果 application-dev.yml 缺失 Redis 配置**：

```yaml
spring:
  data:
    redis:
```

**如果 RedisConfig 缺失**：

```java
package com.community.residence.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.data.redis.connection.RedisConnectionFactory;
import org.springframework.data.redis.core.RedisTemplate;
import org.springframework.data.redis.serializer.GenericJackson2JsonRedisSerializer;
import org.springframework.data.redis.serializer.StringRedisSerializer;

/**
 * Redis 配置
 * 
 * 用途：
 * - JWT 黑名单缓存（DB 双写降级方案）
 * - WebSocket 会话注册表
 * - 通知序号 INCR 计数器
 * - 社区信息缓存
 * - 公告列表缓存
 * - 浏览统计计数
 */
@Configuration
public class RedisConfig {

    @Bean
    public RedisTemplate<String, Object> redisTemplate(RedisConnectionFactory connectionFactory) {
        RedisTemplate<String, Object> template = new RedisTemplate<>();
        template.setConnectionFactory(connectionFactory);
        
        // Key 序列化：String
        template.setKeySerializer(new StringRedisSerializer());
        template.setHashKeySerializer(new StringRedisSerializer());
        
        // Value 序列化：JSON
        GenericJackson2JsonRedisSerializer jsonSerializer = new GenericJackson2JsonRedisSerializer();
        template.setValueSerializer(jsonSerializer);
        template.setHashValueSerializer(jsonSerializer);
        
        template.afterPropertiesSet();
        return template;
    }
}
```

#### 验证标准
- ✅ application-dev.yml 包含 Redis 连接配置
- ✅ pom.xml 包含 redis 和 redisson 依赖
- ✅ RedisConfig.java 存在并配置序列化器
- ✅ 后端启动时 Redis 连接成功（无报错）

### BE-4 ⚠️ WebSocket 配置缺失（优先级：🟡 中，C11 前补充）

#### 问题描述
- WebSocket STOMP 配置缺失
- 影响：C11 消息与通知中心、C6 反馈管理会话功能

#### 修复时机
**不在 P0 阶段修复，留待 C11/C6 模块开发前补充**

#### 修复指南（供 C11 开发前参考）

**创建 WebSocketConfig.java**：

```java
package com.community.residence.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.messaging.simp.config.MessageBrokerRegistry;
import org.springframework.web.socket.config.annotation.EnableWebSocketMessageBroker;
import org.springframework.web.socket.config.annotation.StompEndpointRegistry;
import org.springframework.web.socket.config.annotation.WebSocketMessageBrokerConfigurer;

/**
 * WebSocket 配置
 * 
 * 用途：
 * - C11 通知中心：实时推送通知消息
 * - C6 反馈管理：双向聊天会话
 * 
 * STOMP 协议：
 * - 订阅端点：/user/queue/notifications（个人通知）
 * - 连接端点：/ws
 */
@Configuration
@EnableWebSocketMessageBroker
public class WebSocketConfig implements WebSocketMessageBrokerConfigurer {

    @Override
    public void configureMessageBroker(MessageBrokerRegistry registry) {
        // 启用简单消息代理，前缀 /topic（广播）和 /queue（点对点）
        registry.enableSimpleBroker("/topic", "/queue");
        // 客户端发送消息前缀
        registry.setApplicationDestinationPrefixes("/app");
        // 用户目的地前缀
        registry.setUserDestinationPrefix("/user");
    }

    @Override
    public void registerStompEndpoints(StompEndpointRegistry registry) {
        // 注册 STOMP 端点，允许跨域
        registry.addEndpoint("/ws")
                .setAllowedOriginPatterns("*")
                .withSockJS();
    }
}
```

**验证标准**（C11 开发前）：
- ✅ WebSocketConfig.java 存在
- ✅ @EnableWebSocketMessageBroker 注解启用
- ✅ /ws 端点注册成功
- ✅ 前端可以连接 ws://localhost:8080/ws

### BE-5 ⚠️ 定时任务配置缺失（优先级：🟡 中，C3 前补充）

#### 问题描述
- @EnableScheduling 未启用
- 影响：C3 租住管理（租期判定、到期提醒）、C5 公告管理（自动下线）、C12 房源管理（浏览统计回写）

#### 修复时机
**不在 P0 阶段修复，留待 C3 模块开发前补充**

#### 修复指南（供 C3 开发前参考）

**在主应用类启用定时任务**：

编辑 `backend/src/main/java/com/community/residence/CommunityResidenceApplication.java`：

```java
package com.community.residence;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.scheduling.annotation.EnableAsync;
import org.springframework.scheduling.annotation.EnableScheduling;

/**
 * 社区居住服务管理系统 - 主应用
 */
@SpringBootApplication
@EnableScheduling  // 启用定时任务
@EnableAsync       // 启用异步支持（通知推送 AFTER_COMMIT 异步）
public class CommunityResidenceApplication {

    public static void main(String[] args) {
        SpringApplication.run(CommunityResidenceApplication.class, args);
    }
}
```

**创建定时任务配置类**（可选，用于自定义线程池）：

```java
package com.community.residence.config;

import org.springframework.context.annotation.Configuration;
import org.springframework.scheduling.annotation.SchedulingConfigurer;
import org.springframework.scheduling.concurrent.ThreadPoolTaskScheduler;
import org.springframework.scheduling.config.ScheduledTaskRegistrar;

/**
 * 定时任务配置
 * 
 * 定时任务清单：
 * - 租期判定扫描：每天凌晨 01:00
 * - 到期提醒触发：每天凌晨 01:30
 * - 公告自动下线：每小时整点
 * - 浏览统计回写：每 5 分钟
 * - 黑名单清理：每天凌晨 03:00
 */
@Configuration
public class ScheduleConfig implements SchedulingConfigurer {

    @Override
    public void configureTasks(ScheduledTaskRegistrar taskRegistrar) {
        ThreadPoolTaskScheduler taskScheduler = new ThreadPoolTaskScheduler();
        taskScheduler.setPoolSize(5);
        taskScheduler.setThreadNamePrefix("scheduled-task-");
        taskScheduler.setWaitForTasksToCompleteOnShutdown(true);
        taskScheduler.setAwaitTerminationSeconds(60);
        taskScheduler.initialize();
        
        taskRegistrar.setTaskScheduler(taskScheduler);
    }
}
```

**验证标准**（C3 开发前）：
- ✅ @EnableScheduling 注解已启用
- ✅ 定时任务线程池配置完成
- ✅ 后端启动日志显示 "scheduled-task-" 线程池初始化

```bash
#!/bin/bash
# validate_package_structure.sh

cd backend/src/main/java/com/community/residence

BUSINESS_MODULES=(
  "auth" "community" "resident" "lease" "workorder" "notice" 
  "feedback" "reservation" "evaluation" "statistics" "messaging" "housing"
)

CROSS_CUTTING_MODULES=("config" "common" "filter" "interceptor" "log" "schedule")

echo "=== 验证业务模块包结构 ==="
for module in "${BUSINESS_MODULES[@]}"; do
  if [ ! -d "$module" ]; then
    echo "❌ $module 目录不存在"
    continue
  fi
  
  missing_packages=()
  for package in controller service mapper entity dto vo; do
    if [ ! -d "$module/$package" ]; then
      missing_packages+=("$package")
    fi
  done
  
  if [ ${#missing_packages[@]} -eq 0 ]; then
    echo "✅ $module - 完整"
  else
    echo "⚠️  $module - 缺少：${missing_packages[*]}"
  fi
done

echo ""
echo "=== 验证横切模块 ==="
for module in "${CROSS_CUTTING_MODULES[@]}"; do
  if [ -d "$module" ]; then
    echo "✅ $module - 存在"
  else
    echo "❌ $module - 不存在"
  fi
done
```

运行验证：

```bash
./validate_package_structure.sh
```

## 6. 问题排查

### 6.1 包结构创建失败

**现象**：`mkdir` 命令报错

**排查**：
1. 检查当前目录是否正确（`pwd`）
2. 检查目录权限（`ls -la`）
3. 使用 `-p` 参数自动创建父目录

### 6.2 Git 不追踪空目录

**现象**：创建的空目录无法提交

**解决方案**：
- 方式 1：在每个空目录创建 `.gitkeep` 文件
- 方式 2：创建 `package-info.java` 文件

### 6.3 后端启动失败（JWT_SECRET）

**现象**：后端启动报错 `Could not resolve placeholder 'JWT_SECRET'`

**解决方案**：
```bash
export JWT_SECRET="development-secret-key-change-in-production"
./mvnw spring-boot:run
```

### 6.4 Redis 连接失败

**现象**：后端启动报错 `Unable to connect to Redis`

**排查**：
1. 检查 Redis 是否启动（`redis-cli ping`）
2. 检查 application-dev.yml Redis 配置
3. 检查防火墙是否阻止 6379 端口
