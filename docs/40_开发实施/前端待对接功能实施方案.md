## 2. FE-T2-1：反馈附件上传/删除对接

### 2.1 后端接口现状（BE-ISSUE-9 已修复）

**已实现接口**：
```typescript
// 上传反馈附件
POST /api/v1/feedbacks/{id}/attachments
权限：RESIDENT / ADMIN / SUPER_ADMIN
请求：multipart/form-data, file 字段
响应：AttachmentVO { id, fileName, fileUrl, fileSize, fileType, createdAt }

// 删除反馈附件
DELETE /api/v1/feedback-attachments/{id}
权限：RESIDENT / ADMIN / SUPER_ADMIN
```

**业务规则**：

- 已办结反馈（status=CLOSED）禁止增删附件（返回业务码 5001）
- 管理员受数据级权限约束（仅可操作绑定社区的反馈附件）

```typescript
/**
 * 上传反馈附件
 */
export function uploadFeedbackAttachment(feedbackId: number, file: File) {
  const formData = new FormData()
  formData.append('file', file)
  return request.post<AttachmentVO>(
    `/feedbacks/${feedbackId}/attachments`,
    formData,
    {
      headers: { 'Content-Type': 'multipart/form-data' }
    }
  )
}

/**
 * 删除反馈附件
 */
export function deleteFeedbackAttachment(attachmentId: number) {
  return request.delete(`/feedback-attachments/${attachmentId}`)
}
```

#### 2.2.2 反馈创建页（居民端）

**文件**：`src/views/resident/feedbacks/FeedbackCreateView.vue`

**当前状态**：
- 页面已有 `FileUploader` 组件（P2 T2 文件上传已接入）
- 但上传后的附件未与反馈关联

**改动方案**：

**方案 A（推荐）：两步提交**
1. 用户填写反馈标题/内容，先提交反馈（`POST /feedbacks`），获得 `feedbackId`
2. 用户上传附件，调用 `POST /feedbacks/{feedbackId}/attachments`
3. 提交成功后跳转到反馈详情页（`/resident/feedbacks/{id}`）

**方案 B：延迟上传**
1. 用户在创建页选择附件（暂存在组件 state，不上传）
2. 提交反馈后，获得 `feedbackId`
3. 遍历暂存的附件，逐个调用 `uploadFeedbackAttachment`
4. 全部上传完成后跳转

**推荐方案 A**（理由）：
- 反馈创建与附件上传解耦，失败处理简单
- 用户可在创建后立即看到反馈（附件上传可异步进行）
- 对齐工单附件的"创建后再上传"模式

## 4. FE-T3：WebSocket 实时通知推送

### 4.1 后端接口现状（2026-09-09 已交付）

**WebSocket 端点**：
```
ws://localhost:8080/ws（开发环境）
协议：SockJS + STOMP
认证：CONNECT 帧携带 JWT（headers: {Authorization: 'Bearer {token}'}）

```

**降级兜底**：

### 4.2 前端实现方案

#### 4.2.1 WebSocket 服务封装

**文件**：`src/utils/websocket.ts`（新建）

```typescript
import SockJS from 'sockjs-client'
import { Client, StompSubscription } from '@stomp/stompjs'
import { getToken } from './auth'

type MessageCallback = (message: any) => void

class WebSocketService {
  private client: Client | null = null
  private subscription: StompSubscription | null = null
  private reconnectAttempts = 0
  private maxReconnectAttempts = 5
  private reconnectDelay = 3000
  private isConnecting = false

  /**
   * 连接 WebSocket
   */
  connect(onMessage: MessageCallback) {
    if (this.client?.active || this.isConnecting) {
      console.warn('WebSocket already connected or connecting')
      return
    }

    this.isConnecting = true
    const token = getToken()
    
    if (!token) {
      console.error('No token found, cannot connect to WebSocket')
      this.isConnecting = false
      return
    }

    const socket = new SockJS(import.meta.env.VITE_WS_URL || 'http://localhost:8080/ws')
    
    this.client = new Client({
      webSocketFactory: () => socket as any,
      connectHeaders: {
        Authorization: `Bearer ${token}`
      },
      
      onConnect: () => {
        console.log('WebSocket connected')
        this.isConnecting = false
        this.reconnectAttempts = 0
        
        // 订阅通知队列
        this.subscription = this.client!.subscribe(
          '/user/queue/notifications',
          (message) => {
            const notification = JSON.parse(message.body)
            onMessage(notification)
          }
        )
      },
      
      onStompError: (frame) => {
        console.error('STOMP error:', frame)
        this.isConnecting = false
        this.handleReconnect(onMessage)
      },
      
      onWebSocketClose: () => {
        console.warn('WebSocket closed')
        this.isConnecting = false
        this.handleReconnect(onMessage)
      },
      
      debug: (str) => {
        if (import.meta.env.DEV) {
          console.log('STOMP debug:', str)
        }
      }
    })

    this.client.activate()
  }

  /**
   * 断线重连
   */
  private handleReconnect(onMessage: MessageCallback) {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error('Max reconnect attempts reached, giving up')
      return
    }

    this.reconnectAttempts++
    const delay = this.reconnectDelay * this.reconnectAttempts
    
    console.log(`Reconnecting in ${delay}ms (attempt ${this.reconnectAttempts})`)
    
    setTimeout(() => {
      this.connect(onMessage)
    }, delay)
  }

  /**
   * 断开连接
   */
  disconnect() {
    if (this.subscription) {
      this.subscription.unsubscribe()
      this.subscription = null
    }
    
    if (this.client) {
      this.client.deactivate()
      this.client = null
    }
    
    this.isConnecting = false
    this.reconnectAttempts = 0
    console.log('WebSocket disconnected')
  }

  /**
   * 检查连接状态
   */
  isConnected(): boolean {
    return this.client?.active ?? false
  }
}

export const wsService = new WebSocketService()
```

#### 4.2.2 通知 Store 集成

**文件**：`src/store/notification.ts`（已有，需扩展）

```typescript
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'
import { ElNotification } from 'element-plus'
import { getNotifications, markAsRead, markAllAsRead } from '@/api/notification'
import { wsService } from '@/utils/websocket'
import type { INotification } from '@/types/modules/notification'

export const useNotificationStore = defineStore('notification', () => {
  const notifications = ref<INotification[]>([])
  const lastSeq = ref<number>(0)
  const pollingTimer = ref<number | null>(null)
  
  // 未读数量
  const unreadCount = computed(() => 
    notifications.value.filter(n => !n.isRead).length
  )

  /**
   * 初始化通知系统（登录后调用）
   */
  function init() {
    // 1. 加载历史通知
    loadNotifications()
    
    // 2. 连接 WebSocket
    wsService.connect(handleNotificationPush)
    
    // 3. 启动轮询兜底（每 30 秒检查一次增量）
    startPolling()
  }

  /**
   * 加载历史通知
   */
  async function loadNotifications() {
    try {
      const list = await getNotifications({ page: 1, size: 50 })
      notifications.value = list.records
      
      // 更新 lastSeq（用于增量拉取）
      if (list.records.length > 0) {
        lastSeq.value = Math.max(...list.records.map(n => n.seq))
      }
    } catch (error) {
      console.error('Failed to load notifications:', error)
    }
  }

  /**
   * WebSocket 推送处理
   */
  function handleNotificationPush(notification: INotification) {
    console.log('Received notification:', notification)
    
    // 1. 添加到列表头部
    notifications.value.unshift(notification)
    
    // 2. 更新 lastSeq
    lastSeq.value = Math.max(lastSeq.value, notification.seq)
    
    // 3. 桌面通知
    ElNotification({
      title: notification.title,
      message: notification.content,
      type: getNotificationType(notification.type),
      duration: 5000,
      onClick: () => {
        handleNotificationClick(notification)
      }
    })
  }

  /**
   * 轮询增量拉取（WebSocket 断线兜底）
   */
  function startPolling() {
    if (pollingTimer.value) return
    
    pollingTimer.value = window.setInterval(async () => {
      // 如果 WebSocket 已连接，降低轮询频率
      if (wsService.isConnected()) {
        return
      }
      
      // WebSocket 断线时，通过 HTTP 增量拉取
      try {
        const incremental = await getNotifications({
          sinceSeq: lastSeq.value,
          page: 1,
          size: 20
        })
        
        if (incremental.records.length > 0) {
          incremental.records.forEach(n => {
            notifications.value.unshift(n)
            lastSeq.value = Math.max(lastSeq.value, n.seq)
          })
          
          console.log(`Polled ${incremental.records.length} new notifications`)
        }
      } catch (error) {
        console.error('Polling failed:', error)
      }
    }, 30000) // 30 秒轮询一次
  }

  /**
   * 停止轮询
   */
  function stopPolling() {
    if (pollingTimer.value) {
      clearInterval(pollingTimer.value)
      pollingTimer.value = null
    }
  }

  /**
   * 标记已读
   */
  async function markRead(notificationId: number) {
    try {
      await markAsRead(notificationId)
      const notification = notifications.value.find(n => n.id === notificationId)
      if (notification) {
        notification.isRead = true
      }
    } catch (error) {
      console.error('Failed to mark as read:', error)
    }
  }

  /**
   * 标记全部已读
   */
  async function markAllRead() {
    try {
      await markAllAsRead()
      notifications.value.forEach(n => {
        n.isRead = true
      })
    } catch (error) {
      console.error('Failed to mark all as read:', error)
    }
  }

  /**
   * 清理（登出时调用）
   */
  function cleanup() {
    wsService.disconnect()
    stopPolling()
    notifications.value = []
    lastSeq.value = 0
  }

  /**
   * 通知点击处理（跳转到相关页面）
   */
  function handleNotificationClick(notification: INotification) {
    markRead(notification.id)
    
    // TODO: 根据 notification.type 跳转到对应页面
    // 例如：WORK_ORDER_ASSIGNED → /staff/work-orders/{id}
  }

  /**
   * 通知类型映射（Element Plus 通知类型）
   */
  function getNotificationType(type: string): 'success' | 'warning' | 'info' | 'error' {
    if (type.includes('COMPLETED') || type.includes('APPROVED')) return 'success'
    if (type.includes('REJECTED') || type.includes('CANCELLED')) return 'warning'
    if (type.includes('EXPIRED')) return 'error'
    return 'info'
  }

  return {
    notifications,
    unreadCount,
    init,
    cleanup,
    loadNotifications,
    markRead,
    markAllRead
  }
})
```

**边界条件**：
- 无 token 时连接：❌ STOMP ERROR 帧
- 过期 token 连接：❌ STOMP ERROR 帧，自动重连失败
- Redis 不可用（后端降级）：✅ 推送失败，前端轮询兜底
